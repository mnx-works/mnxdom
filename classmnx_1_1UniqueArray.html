Detailed Description

template<typename T>
class mnx::UniqueArray< T >

Represents an MNX array of simple values that must be unique (JSON schema uniqueItems).

Functions that add or change values refuse to create a duplicate and return false instead. Wrapping existing JSON does not check for duplicates, so schema validation can still report them. Values are compared as JSON values, so elements of other JSON types never match.
